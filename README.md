# ✈️ SkyGo - Book cheap flights with a click!

SkyGo is a responsive PHP-based web app that simulates a flight booking service in the style of Skyscanner or Booking.com. The project leverages a MySQL database for data management and integrates with the Duffel API to simulate flight searches.

**[🚀 Go to Live Demo](https://skygo.wuaze.com/)** | **[📂 GitHub Repository](https://github.com/FrancescoScanni/Sky-Go.git)**

---

## ✨ Features

* **Secure Authentication:** Access and state management handled via PHP Sessions.
* **Responsive Design:** Fluid interface adaptable to any device (desktop, tablet, smartphone).
* **Data Management:** Architecture based on a relational MySQL database.
* **API Integration:** Utilization of the Duffel API for searching and simulating flight data.
* **Privacy & Compliance:** Professional cookie and user consent management integrated via Iubenda.
* **Cloud Hosted:** Application deployed for free and accessible online thanks to InfinityFree hosting.
